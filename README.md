# MCCES HTML

This repository contains an interactive HTML form based on DD Form 2983: Recruit/Trainee Prohibited Activities Acknowledgment.

## Repository contents

- `DD_FORM_2983_v6.html` — the complete interactive form, styled and functional in a single HTML file.

## What the form does

The page includes:

- A printable and PDF-exportable DD Form 2983 layout
- Editable fields for recruit and approver information
- Required-item tracking and stage progression
- Signature and initials capture using a drawing pad or typed signature
- Data export/import support
- Local save-progress behavior in the browser
- Validation prompts for required fields and dates

## How to use it

1. Open `DD_FORM_2983_v6.html` in a web browser.
2. Complete the form as needed.
3. Use the toolbar to:
   - Auto-fill the date
   - Print the form
   - Export PDF
   - Save or import form data
4. Review the status/progress indicators to confirm required fields are completed.

## Notes

- This is a convenience copy of the form intended for digital completion and export.
- It is intended to support data entry and workflow, not to replace the official signed paper form.
- The browser's local save feature stores progress on the device if enabled.

## Technical details

- Technology: HTML, CSS, and JavaScript
- No build step or package installation is required
- Works as a static webpage in any modern browser
